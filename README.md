# Temperature Converter
A simple and responsive Temperature Converter built using HTML, CSS, and JavaScript.  
This app allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

 Features
-  Convert Celsius to Fahrenheit & Kelvin
-  Convert Fahrenheit to Celsius & Kelvin
-  Convert Kelvin to Celsius & Fahrenheit
-  Instant result display
-  Real time value change
-  Accurate calculations

Live Demo: https://bilalmustofa.github.io/Temperature-Converter/
